# Global Rule: Frontend English Language Only

When designing, implementing, updating, or generating any frontend code, UI components, pages, templates, and dialogs:

1. **ENGLISH FOR ALL UI COPY & TEXT**:
   * All user-facing text, headings, body copy, descriptions, placeholders, button labels, toasts, modals, badges, alerts, tooltips, empty states, and error messages MUST be written strictly in **English**.
   * No Indonesian or other non-English languages in UI copy or template labels.

2. **ENGLISH IN CODE ARTIFACTS**:
   * All variables, functions, components, props, emits, types, interfaces, filenames, CSS classes, test descriptions, and ARIA labels (`aria-label`, `aria-describedby`, `title`) MUST be in English.
